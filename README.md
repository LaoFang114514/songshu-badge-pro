>
>PRO 版是用网页（HTML/CSS/JS）来制作兽牌，效果更自由，但需要一点点网页基础
>
>此软件使用的图片素材(包括图标和插图)没有采用AI生成，且永远不会用AI生成

「松鼠兽牌」的进阶版本：将互动网页装进旧手机，立起来就是一块会动、会发光的专属兽牌。支持多兽牌管理、内置编辑器，以及常亮、翻转等展示设置。

---

## ✨ 功能特性

### 🌐 网页兽牌管理
- **三种导入方式** — 单个 HTML 文件、ZIP 压缩包、直接选择整站文件夹，入口文件为 `index.html`
- **主页卡片列表** — 点卡片切换当前兽牌，选中项带主题色描边
- **一牌一文件夹** — 每个兽牌都是独立文件夹，图片、CSS、JS、视频等资源随页面一起管理

### 🖥️ 全屏展示
- **沉浸式体验** — 网页铺满屏幕，系统栏自动隐藏，按返回键退出
- **翻转显示** — 倒置摆放时把画面旋转 180°，触摸坐标同步翻转，点按和滑动方向依然正常
- **常亮与电量** — 展示时屏幕不熄灭，顶部可显示当前电量百分比
- **防烧屏** — 每隔 5 分钟轻微移动画面，减少 OLED 残影
- **长按复制** — 可选择是否允许长按选中网页文字
- **单屏页滚动锁** — 整屏兽牌不会被误拖动，带滚动或手势的页面照常放行

### 📝 内置编辑器
- **文本编辑器** — 行号显示、常用符号快捷栏、未保存修改提醒，理论上支持 HTML / CSS / JS  等


### ⚙️ 实用设置
- **基本设置** — 常亮显示、翻转页面、显示电量、防烧屏、长按复制
- **主题设置** — 跟随系统 / 浅色 / 深色，8 种主题色，Android 12+ 支持莫奈取色
- **数据备份** — 本地导入导出 ZIP；WebDAV 上传备份与恢复
- **使用教程** — 内置导入、编辑、展示、翻转、MCP、备份等图文说明
- **浏览器内核信息** — 查看 WebView 提供方、Chromium 版本与 User-Agent，内核过旧时给出提示

需要学会html、css、js，如果不嫌弃的话，可以使用软件内置的MCP服务。

## 📱 系统要求

- **推荐版本**：Android 10.0 及以上
- **最低版本**：Android 5.0 （不敢保证能否正常使用）
- **架构支持**：armeabi-v7a / arm64-v8a
- **浏览器内核**：建议 Chromium 100 及以上，过旧请到应用商店更新「Android System WebView」
